Alffie

IDOR · broken access control · hard-coded credentials
5.4M documents 500K users
  • IDOR in the documents API exposed 5.4 million documents.
  • IDOR in the booking endpoint leaked user details and allowed custom email sending.
  • Hard-coded AWS credentials provided read, write and delete access to the backend S3 bucket.

  • Exposed data included name, email, phone, address, student ID, Centrelink ID, passport photos and user media.
